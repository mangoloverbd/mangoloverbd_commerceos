FraudShield panel — three options

Same real data in all three, straight from the API doc example: 45 parcels, 42 delivered, 3 cancelled, 93.33% success, risk score 12 (নিরাপদ), seven couriers, one review. Each variant is shown twice — the safe customer, then the same layout with a high-risk customer, because that second one is the state that actually changes what your team does.

Real Geist Sans, real house tokens: #FAFAF8 panels, 8px tracking-[0.3em] labels, font-light hero numbers. The status colours are the ones already in CustomerPanel.tsx for order pills, so nothing new enters the palette. Courier logos are placeholders here — the real ones come down in the payload.

A — Ledgermost house-consistent

Flat and borderless, exactly like the existing detail grid it sits under. No tinted blocks, no cards — the only colour in the whole panel is the risk pill. All seven couriers visible at once. Quietest option; also the tallest.
