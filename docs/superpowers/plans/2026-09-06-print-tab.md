# Print Tab Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a manual `Print` step between `Approved` and `Processing` in the Fulfillment Queue, where only Approved orders can enter Print and courier send moves them to Processing.

**Architecture:** New real `orders.status` value `"print"` classified by the existing shared filter lib (no schema migration). Backend validates Print entry/exit in `PATCH /api/orders/:id` and blocks Approved→courier in both main-order send routes while setting `status: "processing"` on successful send so Print empties deterministically.

**Tech Stack:** TypeScript, React 18, Vitest + Testing Library, Express (single file `server/index.js`), Supabase (no schema change).

## Global Constraints

- Every new route/query keeps the resolved Mango Lover BD `org_id` guard and `getToken` → `getUser` → 401 auth guard.
- No schema migration, no DDL, no new server files; new backend logic goes in the existing Orders/Courier domain sections of `server/index.js`.
- No `.env` changes, no secret handling changes.
- Frontend API calls use `apiFetch()`; new routes use React Router v6 (no new routes needed); icons stay Phosphor light (no new icons needed).
- Shopify sync (`POST /api/fetch-shopify-orders`) is untouched — it upserts without a `status` field so it cannot overwrite `print`.
- InboxOrders page and inbox-order courier routes are untouched (separate social-inbox flow, no Approved/Print concept).

Create `src/lib/orderTransitions.ts`:

```ts
export function normalizeBusinessStatus(value: string | null | undefined): string {
  return (value || "")
    .trim()
    .toLowerCase()
    .replace(/[^a-z0-9]+/g, "_")
    .replace(/^_+|_+$/g, "");
}

export function isApprovedStatus(value: string | null | undefined): boolean {
  const normalized = normalizeBusinessStatus(value);
  return normalized === "approved" || normalized === "confirmed";
}

export function isPrintStatus(value: string | null | undefined): boolean {
  return normalizeBusinessStatus(value) === "print";
}

export function canEnterPrint(fromStatus: string | null | undefined): boolean {
  return isApprovedStatus(fromStatus);
}

export function canLeavePrint(toStatus: string | null | undefined): boolean {
  const normalized = normalizeBusinessStatus(toStatus);
  return (
    normalized === "print" ||
    normalized === "approved" ||
    normalized === "confirmed" ||
    normalized === "cancelled" ||
    normalized === "canceled"
  );
}

export function courierSendBlockReason(status: string | null | undefined): string | null {
  if (isApprovedStatus(status)) return "Move to Print first";
  return null;
}
```
